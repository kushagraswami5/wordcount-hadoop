Big data is a field that treats ways to analyze, systematically extract information from, or otherwise deal with data sets that are too large or complex to be dealt with by traditional data processing software.
Hadoop is an open source framework that allows for the distributed processing of large data sets across clusters of computers using simple programming models.
It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
The Hadoop Distributed File System stores data across many machines. Each file is split into blocks, and each block is copied to more than one machine so that the data survives when a machine fails.
MapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
A MapReduce program is composed of a map procedure, which performs filtering and sorting, and a reduce method, which performs a summary operation.
In the word count example, the map step reads each line of text and emits every word with the number one. The framework then shuffles and sorts the pairs so that all copies of the same word arrive together at one reducer.
The reduce step adds the numbers for each word and writes the final count. Because the work is split across many machines, the same simple program can count the words in a single page or in an entire library.
YARN is the resource manager of Hadoop. It decides which machine runs which task, watches the tasks while they run, and restarts a task on another machine if one fails.
The master node runs the NameNode and the ResourceManager. The worker nodes run the DataNode and the NodeManager, store the blocks, and do the actual computation.
Data locality means that Hadoop tries to run each map task on the machine that already holds the block it needs, so that large amounts of data do not have to travel over the network.
